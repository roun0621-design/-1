PACE RISE : Node — WaveLight 에이전트 · 운영 콘솔
================================================
관리 화면(관리 › 페이싱 라이트)에 저장한 페이싱 설정을 WaveLight 로 가져오고,
경기 진행 상태와 조명 줄 상태를 한 화면에서 봅니다.
WaveLight 컨트롤러와 같은 네트워크에 있고 인터넷이 되는 PC 에 이 폴더를 두고 실행하세요. 설치는 필요 없습니다.

하는 일
-------
1. 파일 맞추기 — 옆의 wavelight 폴더에 .pc2 파일을 항상 최신으로 둡니다.
   (WaveLight 화면의 Complex › Load file 로 손으로 넣을 때 쓰는 파일)
2. 컨트롤러에 올리기 — 콘솔(http://localhost:5010)에서 종목 옆 「올리기」를 누르면
   색마다 빈 줄에 구간·색·출발선이 들어가 "출발 신호 대기" 상태가 됩니다. 올리는 것만으로는 조명이 출발하지 않습니다.
3. 운영 콘솔 — 경기 진행 상태(예정·진행 중·완료)와 조명 줄 10개의 상태(비어 있음·대기·진행 중)를 나란히 보여 주고,
   맞는지 한 문장으로 알려 줍니다. 출발(Fire)과 취소도 여기서 합니다.
에이전트는 조명 전원·밝기를 건드리지 않고, 취소는 이 콘솔에서 올린 줄만 합니다.

처음 한 번
----------
1. config.json 을 메모장으로 열어 두 칸을 채웁니다.
     "competition_id": 대회 번호 — 관리자 화면 주소의 id (예: admin.html?id=63 → 63)
     "controller": WaveLight 화면을 여는 주소 (예: http://192.168.1.240:5001)
2. Windows: 「시작.bat」을 두 번 클릭 / Mac: 「start.command」를 두 번 클릭.
   검은 창에 "WaveLight 에이전트 v… 시작" 과 "콘솔: http://localhost:5010" 이 보이면 됩니다. 창을 닫으면 멈춥니다.
3. 이 PC 의 브라우저에서 http://localhost:5010 을 엽니다.

경기 때
-------
1. 「연결」 칸: 서버 "받음", 컨트롤러 "연결됨", 조명 전원 "켜짐". (조명 전원은 WaveLight 화면에서 켭니다)
2. 「종목」에서 색·기록과 「출발선 조명」을 확인하고 「올리기」. 「구간 보기」로 자동으로 만들어진 구간표를 볼 수 있습니다.
   출발선 조명은 결승선에서 끝나도록 계산한 값입니다(1500m → 100, 3000m·5000m → 200, 800m·10000m → 0).
   3000m 장애물은 WaveLight 에 저장해 둔 사용자 지정 출발선(Lamp …)이 있으면 그 값을 씁니다. 현장과 다르면 숫자를 고친 뒤 올리세요.
3. 「경기와 조명」 칸에 "조명이 출발 신호를 기다립니다"가 보이면 준비된 것입니다. 출발 신호에 「Fire」.
   (WaveLight 화면의 Fire 나 출발 신호 장치로 출발해도 콘솔이 알아챕니다)
4. 「조명 줄」에서 줄마다 경과 시간과 진행 막대를 봅니다. 끝나면 줄이 스스로 비워집니다.
5. 잘못 올렸으면 줄 옆 「취소」 또는 「올린 줄 모두 취소」.

자동 올리기
-----------
「경기가 진행 중이 되면 자동으로 올리기」를 켜면, 소집이 끝나 경기가 '진행 중'으로 바뀌는 순간 그 종목을 대기로 올립니다.
출발은 언제나 사람이 합니다. 에이전트를 켠 뒤에 바뀐 것에만 반응합니다(이미 진행 중이던 경기는 올리지 않습니다).

기록
----
한 일은 옆의 logs 폴더에 날짜별 파일로 남습니다(올리기·컨트롤러 응답·Fire·끝난 시각·취소·경기 상태 변화).

알아 둘 것
----------
- 콘솔에서 올린 줄은 WaveLight 화면의 칸(meter / time)에 숫자로 보이지 않습니다. 줄 번호가 빨갛게 바뀝니다.
- 빈 줄이 모자라면 올리지 않습니다. 안 쓰는 줄을 취소하세요.
- 한 바퀴 조명이 400개인 트랙 기준입니다. 다른 구성(200개)에는 올리지 않습니다.
- 인터넷이 끊겨도 마지막으로 받은 내용으로 올릴 수 있습니다.
- wavelight 폴더에 직접 넣어 둔 다른 .pc2 파일은 건드리지 않습니다.

config.json 항목
----------------
server         서버 주소 (기본 https://pace-rise-node.com)
competition_id 대회 번호
controller     WaveLight 주소 (비우면 파일 맞추기만 합니다)
dir            .pc2 를 둘 폴더 (비우면 옆의 wavelight 폴더)
interval       서버 확인 주기(초, 기본 5)
port           콘솔 번호 (기본 5010)
host           조직 서브도메인으로 받을 때 (예 jp.pace-rise-node.com, 선택)
