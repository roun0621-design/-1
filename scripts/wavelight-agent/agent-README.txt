PACE RISE : Node — WaveLight 에이전트
=====================================
관리 화면(관리 › 페이싱 라이트)에 저장한 페이싱 설정을 WaveLight 로 가져옵니다.
WaveLight 컨트롤러와 같은 네트워크에 있고 인터넷이 되는 PC 에 이 폴더를 두고 실행하세요. 설치는 필요 없습니다.

하는 일
-------
1. 파일 맞추기 — 옆의 wavelight 폴더에 .pc2 파일을 항상 최신으로 둡니다.
   관리 화면에서 저장하면 몇 초 안에 이 폴더의 파일이 바뀝니다. (WaveLight 화면의 Complex › Load file 로 손으로 넣을 때 쓰는 파일)
2. 컨트롤러에 올리기 — 이 PC 의 브라우저에서 http://localhost:5010 을 열고 종목 옆 「올리기」를 누르면
   색마다 빈 줄에 구간·색·출발선이 들어가 "출발 신호 대기" 상태가 됩니다.
   출발은 평소처럼 WaveLight 화면의 Fire(또는 출발 신호)로 합니다. 에이전트는 조명을 출발시키지 않고, 전원·밝기도 건드리지 않습니다.

처음 한 번
----------
1. config.json 을 메모장으로 열어 두 칸을 채웁니다.
     "competition_id": 대회 번호 — 관리자 화면 주소의 id (예: admin.html?id=63 → 63)
     "controller": WaveLight 화면을 여는 주소 (예: http://192.168.1.240:5001)
2. Windows: 「시작.bat」을 두 번 클릭 / Mac: 「start.command」를 두 번 클릭.
   검은 창에 "WaveLight 에이전트 v… 시작" 과 "보내기 화면: http://localhost:5010" 이 보이면 됩니다. 창을 닫으면 멈춥니다.

경기 때
-------
1. 보내기 화면에서 「연결」 칸을 봅니다: 서버 "받음", 컨트롤러 "연결됨", 조명 전원 "켜짐".
   (조명 전원은 WaveLight 화면에서 켭니다)
2. 종목의 색·기록과 「출발선 조명」을 확인하고 「올리기」.
   출발선 조명은 결승선에서 끝나도록 계산한 값입니다(1500m → 100, 3000m·5000m → 200, 800m·10000m → 0).
   3000m 장애물은 WaveLight 에 저장해 둔 사용자 지정 출발선(Lamp …)이 있으면 그 값을 씁니다. 현장과 다르면 숫자를 고친 뒤 올리세요.
3. WaveLight 화면에서 그 줄들이 빨갛게 바뀌고 Fire 가 켜집니다. 출발 신호에 Fire.
4. 잘못 올렸으면 「올린 줄 취소」(에이전트가 올린 줄만 취소합니다). WaveLight 화면의 Cancel 로 지워도 됩니다.

알아 둘 것
----------
- 올린 줄은 WaveLight 화면의 칸(meter / time)에 숫자로 보이지 않습니다. 줄 번호가 빨갛게 바뀌는 것으로 확인합니다.
- 빈 줄이 모자라면 올리지 않습니다. WaveLight 화면에서 안 쓰는 줄을 Cancel 하세요.
- 한 바퀴 조명이 400개인 트랙 기준입니다. 다른 구성(200개)에는 올리지 않습니다.
- 인터넷이 끊겨도 마지막으로 받은 내용으로 올릴 수 있습니다.
- wavelight 폴더에 직접 넣어 둔 다른 .pc2 파일은 건드리지 않습니다.

config.json 항목
----------------
server         서버 주소 (기본 https://pace-rise-node.com)
competition_id 대회 번호
controller     WaveLight 주소 (비우면 파일 맞추기만 합니다)
dir            .pc2 를 둘 폴더 (비우면 옆의 wavelight 폴더)
interval       서버 확인 주기(초, 기본 10)
port           보내기 화면 번호 (기본 5010)
host           조직 서브도메인으로 받을 때 (예 jp.pace-rise-node.com, 선택)
