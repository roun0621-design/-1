PACE RISE : Node — 계측 에이전트
=================================
계측 PC(FinishLynx 등)에서 나온 결과 파일(.lif, .txt)을 inbox 폴더에 넣기만 하면
서버에 자동으로 올라가 기록이 들어갑니다. 설치가 필요 없고, 이 폴더만 있으면 됩니다.

처음 한 번
----------
1. config.json 을 메모장으로 열어 두 칸을 채웁니다.
     "key": 운영키  — 관리자 › 계정·키 › 심판 운영키에서 "계측 PC" 전용으로 하나 발급해 쓰세요.
     "competition_id": 대회 번호 — 관리자 화면 주소의 id (예: admin.html?id=63 → 63)
   그 외는 비워 두면 됩니다. (dir 을 비우면 옆의 inbox 폴더를 지켜봅니다)
2. Windows: 「시작.bat」을 두 번 클릭 / Mac: 「start.command」를 두 번 클릭.
   검은 창에 "에이전트 v… 시작" 이 보이면 됩니다. 창을 닫으면 멈춥니다.
3. (선택) Windows 「자동시작 등록.bat」을 한 번 실행하면 PC 를 켤 때마다 자동으로 켜집니다. 「자동시작 해제.bat」으로 되돌립니다.

평소
----
- FinishLynx 의 결과 저장 폴더를 이 inbox 로 지정하거나, 파일을 inbox 에 복사하세요.
- 올라간 파일은 done 폴더로, 확인이 필요한 파일은 review 폴더로(같은 이름의 .log 에 이유), 실패는 failed 폴더로 옮겨집니다.
- review 에 들어간 파일은 관리자 화면 › 가져오기 › 계측 › .lif 에서 손으로 올리면 됩니다.
- 관리자 화면의 .lif 카드 위에 "계측 에이전트 ○○ 연결됨 · 적용 n건" 이 보이면 정상입니다.

자주 걸리는 것
--------------
- "조를 못 찾음": .lif 머리글의 종목 이름이 조의 전광판 키와 다릅니다 → 관리자 › 종목 › 조에서 키를 맞추거나 계측 PC 의 종목 이름을 "남자 100m 예선 1조" 형식으로.
- "서버 연결 실패": 인터넷/방화벽을 확인하세요. 서버 주소(server)가 맞는지도.
- "운영키(key)와 대회 번호(competition_id)가 필요합니다": config.json 을 다시 확인하세요.
- 종료된 대회에는 운영키로 못 올립니다(관리자가 대회를 다시 열거나 관리자 키 사용).

config.json 항목
----------------
server         서버 주소 (기본 https://pace-rise-node.com)
key            운영키
competition_id 대회 번호
dir            감시 폴더 (비우면 inbox)
mode           auto: 모두 매칭되면 바로 적용(기본) / confirm: 미리보기만 하고 review 로
interval       폴더 확인 주기(초, 기본 3)
notify_url     실패·확인 필요 때 알릴 웹훅 주소(슬랙 등, 선택)
host           조직 서브도메인으로 올릴 때 (예 jp.pace-rise-node.com, 선택)
name           이 PC 이름 (비우면 컴퓨터 이름)
