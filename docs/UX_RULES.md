# 화면 규칙집 (UX Rules)

2026-09 사용성 점검에서 정한 규칙. 새 화면·새 기능은 이 규칙을 따른다. 공통 구현은 모두 `public/common.js` 에 있다.

## 1. 파일 올리기
- **모든 파일 선택 칸은 끌어다 놓기가 된다.** 칸마다 따로 만들지 않는다 — `common.js` 가 문서 전체에서 처리한다(놓은 위치에서 위로 올라가며 파일 칸이 하나뿐인 영역을 찾아 그 칸에 넣고 `change` 를 낸다).
- 새 업로드 칸은 `<input type="file" accept="…">` 만 두면 된다. `accept` 는 반드시 적는다(형식 검사에 쓴다).
- 한 영역에 파일 칸을 두 개 이상 두지 않는다(어느 칸인지 알 수 없어 끌어다 놓기가 꺼진다). 나란히 둘 때는 칸마다 감싸는 `<div>` 를 둔다.
- 자체 드롭 영역(.txt/.lif/기록카드 미리보기)은 `stopPropagation` 을 하므로 공통 처리와 겹치지 않는다.

## 2. 알림 · 확인 · 입력
| 상황 | 쓰는 것 | 쓰지 않는 것 |
|---|---|---|
| 결과를 잠깐 알림(저장됨, 복사됨) | `showToast(msg, 'success'|'error'|'warning', ms)` | `alert` |
| 읽고 확인해야 하는 안내·오류 | `await uiAlert(msg)` | `alert` |
| 예/아니오 | `await uiConfirm(msg)` → `true/false` | `confirm` |
| 값 입력 | `await uiPrompt(msg, 기본값)` → 문자열 / 취소 시 `null` | `prompt` |

- 삭제·초기화·덮어쓰기처럼 되돌리기 어려운 작업은 문구에 그 단어를 쓴다 → 확인 버튼이 빨강이 되고 처음 초점이 **취소**에 간다(Enter 연타로 실행되지 않는다). 직접 지정: `uiConfirm(msg, { danger: true })`.
- 키·비밀번호를 묻는 입력창은 자동으로 가려진다.
- 예외(기본 창 유지): 알림 직후 페이지를 옮기는 곳, 동기 함수 안(`confirmCompletedEdit`, `checkUnsavedBeforeAction` 등 11곳), `common.js` 를 싣지 않는 페이지(`account.html`, `event-record.html`).
- 저장 실패는 **반드시 화면에 알린다.** `catch (e) { console.error(e) }` 만 두지 않는다. 기록 입력 화면은 `_recSaveFailed(무엇, err, true)` — 알림 + 서버 값으로 되돌림.

## 3. 버튼
- 창·폼의 버튼은 **오른쪽 정렬, `취소` 다음에 주 버튼**(`저장`·`추가`·`발급`). 삭제 같은 파괴적 버튼은 같은 줄 **왼쪽 끝**에 떼어 둔다.
- 주 버튼 문구는 동작을 말한다: `저장`, `추가`, `업로드`, `발급`, `PDF 열기`. `확인`은 안내창을 닫을 때만.
- 태블릿에서 누르는 버튼은 높이 44px 이상.

## 4. 오프라인 · 저장 상태
- 연결이 끊겨도 임시 저장되는 것은 **심판 기록 입력 6종뿐**이다(`sw.js` 의 `QUEUEABLE`). 그 밖의 쓰기는 실패를 그대로 알린다. 새 입력 API 를 큐에 넣으려면 "같은 요청을 두 번 보내도 결과가 같은가"를 먼저 확인한다.
- 서버가 거부한 임시 저장분은 '반영되지 않은 입력' 목록으로 보여준다 — 조용히 버리지 않는다.

## 5. 용어
| 쓴다 | 쓰지 않는다 | 비고 |
|---|---|---|
| 소집 / 소집실 | 콜룸, 콜룸실 | 영문 병기는 `Call Room` |
| 배번 (문장) · `BIB` (표 머리글) | 빕, 등번호 | |
| 조 | 히트 | 영문 병기는 `Heat` |
| 시기 (필드 1~6차 시기) | 차수, 시도 | 높이 종목의 O/X 는 `시도` |
| 경기 완료 / 소집 완료 | 종료, 마감 | 대회 단위는 `대회 종료` |
| 상장(순위) · 기록증(기록만) · 완주증 | 증서 | 워드 상장 = 현장 인쇄, PDF = 문자 발송 |
| 종합경기 (10종·7종·5종) | 혼성경기, 혼성 | '혼성'은 혼성 계주(남녀 혼합)에만 쓴다. 코드 카테고리 값은 `combined` 그대로 |
| ID카드 | AD카드, 인가증 | 화면 표기는 `ID카드 (AD카드)` |

- 화면 문구는 한국어. 영어 알림(`Online`, `Offline mode`)은 쓰지 않는다.
- **계주 종목명 저장값은 `4X100mR` · `4X400mR` · `4X800mR` · `4X1500mR` · `4X400mR(Mixed)`** (대문자 X). 곱셈 기호(`4×800mR`)로 저장되던 것은 부팅 시 자동 변환된다. 입력(엑셀·시간표·.lif)은 `x`/`X`/`×` 모두 받는다. 문서(종합기록지)는 양식에 맞춰 `4x100mR` 로 바꿔 쓴다 — 이름 정규화 함수 4곳을 한 모듈로 합치는 일은 Phase 4.

## 6. 캐시 버전
- **손으로 올리지 않는다.** 서버가 HTML 을 내보낼 때 `xxx.js?v=…`·`xxx.css?v=…` 를 파일 내용 해시로 바꿔 쓰고, `sw.js` 의 `CACHE_NAME` 도 자원 전체 해시로 바꿔 쓴다(`lib/assetVersion.js`). 파일만 고치고 배포하면 된다. HTML 안의 `?v=` 값은 자리표시일 뿐이다.

## 7. 숫자·날짜 표기 (현재 구현 = 규칙)
| 값 | 표기 | 함수 |
|---|---|---|
| 트랙 기록 | `10.52` · `1:52.34` · `1:02:15.30` — 저장된 자리수만큼(1/1000초는 있을 때만) | `formatTime(s)` |
| 거리 | 입력 `7.26`, 표시 `7.26m` | `v.toFixed(2) + 'm'` |
| 높이 | `1m70` | `formatHeight(m)` |
| 풍속 | `+1.2` / `-0.3` (부호 항상) | `formatWind(w)` |
| 날짜 | `2026-09-14` (ISO), 기간은 `2026-09-14 ~ 2026-09-16`. 상장·문서에서만 `2026년 9월 14일` | — |
| 시간 | `08:30` 24시간 | — |
- `toLocaleDateString` 은 쓰지 않는다(브라우저마다 `2026. 9. 14.` 처럼 달라진다).

## 8. 상태코드(DNS/DNF/DQ/NM) 표기·정렬 — 모든 결과 화면·문서 공통
- 순서: **완주(순위) → NM → DNF → DQ → DNS**. 상태코드 선수는 순위가 없고, 기록이 남아 있어도(실격 뒤 기록) 순위에 들지 않는다.
- 표기: 기록란에 코드(`DQ`), 비고란에 사유(심판 비고: 규칙 번호 등). 화면 표에서는 `DQ (TR 16.8)` 처럼 코드 뒤 괄호에 사유.
- 구현은 한 곳: `public/lib/ranking.js` 의 `isStatus` · `compareStatus` · `withStatusLast(cmp)` · `statusText(code, reason)`. 새 결과 렌더러는 상태코드 목록을 직접 쓰지 말고 이 함수를 쓴다.

## 9. 파괴 동작은 되돌릴 수 있게
- 삭제·초기화 라우트는 지우기 전에 `lib/undo.js` 의 `snapshot()` 으로 지워질 행을 저장하고 응답에 `undo_id` 를 넣는다. 화면은 `showUndoToast(메시지, undo_id, 되살린 뒤 콜백)` 으로 10초 '되돌리기' 버튼을 보여준다.
- 확인창에 "되돌릴 수 없습니다" 라고 쓰지 않는다 — 24시간 안에 되돌릴 수 있고, 그 뒤엔 백업 복원이다.
- 새 파괴 동작을 만들 때 스냅샷 없이 지우면 안 된다.

## 10. 빈 상태 · 불러오는 중 · 실패 — 세 상태는 한 모양
- 목록·표가 비었으면 `uiStateHtml('empty', { title, hint, action })`: 제목은 "무엇이 없는지", 안내는 "어떻게 하면 생기는지", 버튼은 다음 행동(권한 있을 때만).
- 불러오는 동안은 `uiState(el, 'loading', { title })` — 빈 표를 먼저 보여주지 않는다.
- 실패는 `uiState(el, 'error', { title, hint })`: 서버 메시지는 힌트에 글자로(태그 이스케이프), 기본 버튼은 '다시 시도'. `console.error` 만 하고 화면을 비워 두지 않는다.
- 스타일은 `styles.css .ui-state` 하나. 페이지마다 inline 스타일로 새로 만들지 않는다.

## 11. 키보드·단축키
- 입력 화면의 공통 키: `Enter` 저장 · `Esc` 취소/닫기 · `Tab`/`↓` 다음 · `Shift+Tab`/`↑` 이전 · `Ctrl/⌘+S` 현재 조 전체 저장(트랙). 새 입력 칸을 만들면 이 네 가지부터 맞춘다.
- 페이지마다 `registerShortcuts('제목', [[키, 설명]])` 로 표를 등록하면 헤더의 `?` 버튼과 `?` 키로 열린다. 문서에만 적고 등록하지 않는 단축키는 없는 것으로 친다.

## 12. 접근성·가독성
- 글자: 본문 13px 이상, 배지·라벨·표 머리글도 11px 아래로 내려가지 않는다(`font-size: 9px/10px` 금지).
- 색: 보조 글자 `--text-muted`(#6d7380, 4.7:1)·`--text-light`(#7a8190) 토큰만 쓴다. 상태는 색 + 글자(코드·라벨)로, 색만으로 구분하지 않는다.
- 포커스: 전역 `:focus-visible` 금색 테두리. 개별 요소에서 `outline: none` 을 쓰지 않는다.

## 13. 페이지 구조·이동
- 모든 운영 페이지는 `renderPageNav`(헤더·탭·뒤로/앞으로/새로고침/?/로그인) + `renderCompInfoBar`(대회명·기간·장소·기록지·시간표) 두 공통 셸을 쓴다. 페이지가 헤더를 따로 그리지 않는다.
- 대회 바꾸기는 대회 정보줄의 대회명 옆(볼 만한 대회가 둘 이상일 때)에서 — 어느 페이지에서나 같은 자리. 같은 페이지의 다른 대회로 이동한다.
- 현재 위치는 헤더 탭의 활성 표시로. 뒤로가기(브라우저·기기)는 열린 창(모달)만 닫고 페이지를 떠나지 않는다(common.js 모달 스택).

## 14. 폰 글자 크기 (2026-09-22)
- 폰(짧은 변 720px 미만)에서는 페이지를 **1.125배**로 보여준다. 방법은 CSS zoom 이 아니라 viewport 메타(`width=화면폭÷배율, initial-scale=배율`) — vh·fixed·핀치 줌이 그대로 맞는다(`common.js applyPhoneTextScale`).
- iOS 는 여기에 사용자의 **텍스트 크기 설정**(`-apple-system-body`, 기본 17px)을 곱한다 → 글씨를 키워 둔 사람에겐 더 크게, 기본인 사람은 1.125배. 상한 1.4배. 안드로이드 크롬은 시스템 글꼴 배율을 스스로 적용하므로 기본 배율만.
- 전광판·모니터처럼 `user-scalable=no` 인 페이지는 건드리지 않는다. 기록입력·소집실의 A−/A+ 는 그 위에 따로 동작.

## 15. 폰 대시보드 필터 (2026-09-22)
- 폰(640px 이하)에서는 성별·종목군·부 칩 줄 대신 **필터 버튼 하나**(`⌄ 전체`) — 누르면 아래 패널에 `성별 / 종목군 / 부` 줄이 알약으로 펼쳐진다. 버튼 글씨가 현재 상태(`여자 · 필드`), 걸려 있으면 남색 채움. 대회에 있는 성별·종목군·부만 보여준다. PC 는 칩이 그대로(상태는 공유).
- '한국 선수'는 필터 밖에 둔다(가장 많이 누르는 버튼). 폰의 종목 검색은 필터 패널 맨 위 검색칸(툴바 돋보기는 PC 만). 검색어가 있으면 버튼 글씨에 “400” 처럼 보인다. 결과가 없으면 "조건에 맞는 종목이 없습니다 → 필터 초기화".


## 16. 대시보드 기본 정렬·현재 위치 (2026-09-24)
- 기본 정렬은 **시간별**(모든 대회 공통, 시간표가 있을 때). 사용자가 종목별로 바꾸면 대회별로 기억.
- 시간별에서는 끝난 종목만 칩 없음(날짜 섹션이 대신), 진행 중·예정은 시간 칩. 종목별에서는 앞으로 할 종목 날짜+시간, 끝난 종목은 날짜만.
- 시간별로 처음 열면 진행 중 > 지금 이후 첫 종목 > 마지막 종목 순으로 카드에 부드럽게 스크롤하고 금색 테두리 두 번 깜빡임(`_scrollToNow`, 세션당 한 번). 7종·10종은 며칠 내내 LIVE라 대상에서 뺀다.
- 카드에서 '종료·예정' 배지와 '예선·준결승 없음' 줄은 뺐다 — 라운드 버튼이 상태를 말한다.
- 결과·LIVE·스타트 리스트 창의 '기존 기록' 칩(국제대회: WR·AR·GR·NR 네 개, 폰에서 한 줄에 균등 폭)은 라벨+기록만. 탭하면 띠 아래 한 줄로 `WR 세계기록 · 이름 · 팀 · 연도`(같은 칩 다시 탭하면 접힘, 다른 칩 탭하면 바뀜). 창을 띄우지 않는다.
