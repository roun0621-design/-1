## 1. 타이포그래피
- 6단계만: **12 캡션 / 13 보조 / 14 본문 / 16 카드 제목 / 20 화면 제목 / 28 KPI 숫자**(tabular-nums). **10·11px 금지**(폰 관전 화면 포함, `UX_RULES §14`).
- 본문 글꼴은 기존 시스템 폰트, 숫자·시각·배번은 등폭(D2Coding/mono) — 칩 안 글자도 등폭으로 맞춰야 세로 정렬이 어긋나지 않는다(NEXT 칩 사례).
- 제목에 영문 부제·기술 용어(JWT, API 키 이름, 파일 경로, 컬럼명) 넣지 않는다. 필요하면 툴팁/도움말.

## 2. 아이콘·기호
- 선(line) 아이콘 단일 세트(`public/lib/icons.js`, 관리자는 `ICON_PATHS`), 20px 기준, 선 굵기 자동(≈1.2px@16 → 1.6~3.6 범위).
- **이모지·유니코드 기호·알파벳 원형 배지 금지**: ⚠ ⭐ ♂ ♀ ※ ① ② ▼ ○ ● ★ 그리고 "R/S/U/L/J/E/G" 같은 글자 배지. 성별은 텍스트 칩(남/여/혼 · M/W/X).
- 닫기 X 는 전 화면 `prCloseBtn()` 하나. 새로고침·메뉴·외부링크·검색 아이콘도 한 세트에서만.
- 버튼 라벨에 기호만 쓰지 않는다(▶ ↗ × • 금지 → 미리보기 / 열기 / 제거 / 키 없음 처럼 낱말로). 트리 표시(├ └)도 쓰지 않는다 — 들여쓰기 + 상태 점(CSS 8px 원)으로.

## 3. 색
- 브랜드 골드(`#b79f58`)는 **Primary 액션과 활성 상태에만**. 의미색 4가지 고정: 성공 초록 / 주의 주황 / 오류 빨강 / 정보 파랑. 회색 6단계.
- 색은 의미가 있을 때만 쓴다. 카드 좌측 컬러 보더, 파스텔 배경 설명 상자, 색깔 카드 제목, "단계"를 색으로 구분하는 것 — 전부 금지.
- 라운드 글자색: 예선 파랑 · 준결승 주황 · 결승 빨강(대시보드·데일리 카드 공통).
- 성별 색: 남 남색 / 여 자주 / 혼성 골드(카드 좌측 성별 바, 칩).

## 4. 카드·레이아웃
- 카드 한 종류: 흰 배경 · 1px 보더 · 8px 라운드 · 20~24px 패딩. **카드 속 카드 금지**(구획은 구분선 + 12px 대문자 레이블).
- 화면당 스크롤 2장 이내. 길면 **서브탭(가로)** 또는 **단계(스텝 바)** 로 나눠 한 번에 하나만 보인다.
- 사이드바는 화면만 나열(카드 앵커 없음), 6묶음(현황·대회·준비·진행·결과·문서·시스템), 900px 높이에 스크롤 없이.
- 대회를 고르면 그 대회에 해당하는 화면만(국제 동기화·중고연맹 기록지·행사 브랜딩). 위험 작업(초기화·삭제)은 화면 맨 아래 '위험 구역' 한 카드, 확인 모달 필수, 메뉴에 노출 금지.
- 폰(393px): 성별 탭·필터 패널·정렬 토글은 한 줄, 겹치지 않게. 터치 대상 ≥ 40px. 창 스크롤 잠금은 횟수 세기(`lockBodyScroll`).

## 5. 버튼·입력
- 버튼 4종만: **Primary(골드 채움, 화면당 1개) / Secondary(아웃라인) / Tertiary(텍스트+아이콘) / Destructive(빨강 아웃라인 + 확인 모달)**. 높이 32px, 표 안 28px. 초록·파랑·청록 채움 금지. 파일 형식(Excel/PDF/Word)은 색이 아니라 라벨.
- 파일 입력은 **드롭존 컴포넌트 하나**(`.adm-drop`: 끌어다 놓기·클릭·파일명 표시) → 미리보기(아웃라인) → 실행(Primary) 순서·배치 동일. 브라우저 기본 파일 버튼 금지.
- 설명은 카드당 한 줄(`.adm-lead`). 열 정의·예시는 **'형식 안내' 접이식**(`details.adm-help`) 한 종류.
- 새로고침은 우측 상단 아이콘 버튼, 결과는 토스트 없이 버튼 안 ✓(0.8초).

## 6. 표·목록·빈 상태
- 표: 헤더 12px 회색, 행 40px(관리자)·폰 카드 1행, 하단 1px 구분선, 숫자 우측 정렬 tabular-nums, 상태는 배지 열, 행 액션은 hover 아이콘(상시 소형 버튼 87개 같은 것 금지).
- 큰 목록(선수 817·시간표 87·종목 72)은 전폭 표 + 검색/필터 + 우측 드로어. 표는 **화면 안 스크롤 영역**(높이 = 화면 − 300px, 머리글 sticky)에 넣어 페이지 자체가 수만 px 로 길어지지 않게. 매칭 현황처럼 100% 정상이면 요약 한 줄만, 문제 있을 때만 펼침.
- 드로어: 제목 바(대상 이름 + 닫기 아웃라인 버튼, sticky) + 어두운 백드롭(클릭·ESC 로 닫힘), 폭은 선수 480 / 종목 820px, 폼은 2열 그리드, 삭제(Destructive)는 저장과 같은 줄 맨 오른쪽으로 떨어뜨린다. 값이 비는 열(학년 등)은 표에서 자동으로 뺀다.
- 빈 상태 컴포넌트 하나: 32px 선 아이콘 + 제목 1줄 + 설명 1줄 + CTA 1개. 텍스트 'USER'·'E' 같은 임시 표시 금지. 내용 없는 카드는 렌더하지 않는다.
- 로딩·실패도 같은 모양(`UX_RULES §10`).

## 7. 대시보드·결과 화면 (관전)
- 기본 정렬 시간별, 열면 '지금' 종목이 화면 **중앙**. 진행 중 = LIVE 배지 깜빡임, 다음 = NEXT 칩 깜빡임(JS 토글 — iOS 동작 줄이기 대응). 테두리 깜빡임 금지. 끝난 대회·지난 날짜엔 NEXT 없음. 7종·10종은 LIVE 대상 아님.
- 완료된 경기만 시간 칩 제거, 진행·예정은 유지.
- 결과·LIVE 창 제목 두 줄: `LIVE칩 + 성별` / `종목 라운드`. 순서는 언제나 성별 → 종목 → 라운드.
- 기존 기록 칩 WR·AR·GR·NR 한 줄, 탭하면 아래 한 줄로 `WR 세계기록 · 이름 · 팀 · 연도`. NR 을 이 대회에서 세우면 칩 빨강 채움 + `종전 …`.
- 스타트리스트: 행에 `5/7`(PB 순번) 을 PB 앞에, 한국 선수 블록엔 `RANK 5/7 · 전체 23/25`. 우측 열 순서 기록 / 순위 / 진출 / PB.
- 국제대회: 결과 줄의 기록 카드(›) 숨김, 네이버 검색은 `아시안게임 육상 이름`, 선수명은 EN/JA 에서 라틴 이름 우선.
- 결과 이미지: 1080×1350(17명↑ 1080×1920), 조마다 한 장, 사파리·홈화면앱=공유창, 앱스토어 앱=전체 화면.

## 8. 다국어
- 시스템 언어 KO/EN/JA, **영어 우선**. 원문(한국어)이 키, 사전 `public/locales/*.json`, 도구 `scripts/i18n/`(extract → parts → build). 새 한국어 문장을 넣으면 같은 커밋에서 EN/JA 도 추가(`extract.js --missing`).
- 격자 열 머리글이 이미 라운드(예선/준결승/결승)를 말해주면 칩 안에는 라운드를 반복하지 않는다 — 기록입력·소집실 종목 목록 칩은 `기록`/`명단`(Mark/List · 記録/リスト)만, 12px nowrap.
- 서버가 만드는 문구(운영 체크리스트·readiness, 오류 메시지)도 원문이 키이므로 같은 커밋에서 EN/JA 를 `*.overrides.json` 에 넣는다. 저장된 데이터(운영 로그 메시지·이름)는 번역 대상이 아니다.
- 긴 언어 대비: 칩·탭·표 머리글·버튼은 **짧은 라벨 세트**(Res./List·Event/Time·H/SF/F)를 우선, 버튼은 한 줄(nowrap), 일본어는 글자 단위 줄바꿈 금지. 넘침은 `node scripts/i18n/overflow_check.js both`(BASE·ADMIN_PW 환경변수) 로 **0건**을 확인하고 나서 커밋한다(2026-10-01 기준 0건).
- 대회명은 `competition.name_en/name_ja`, 종목·라운드·부 라벨은 `lib/eventCatalog.js`·`lib/labels.js`.

## 9. 이름 짓기·문구
- 화면 이름: 상장 → **상장·기록증**, 양식 카드 → **PDF 상장 양식 / 워드 상장 양식**, 문서 → **문서·다운로드**, 계측 → **계측 가져오기**, 업로드 → **가져오기**.
- 화면에 보이는 값은 대회 설정(대회명·기간·장소·시간대·상태·브랜딩), 종이에 찍히는 값은 문서(서명·로고·양식).
- 오류·안내 문구는 사용자 행동 기준으로("대회를 먼저 선택하세요"), 기술 상태("SQLite 전용", "PostgreSQL 모드") 는 화면에 내지 말고 해당 UI 를 숨기거나 대체한다.
- 이메일 `info@pace-rise.com`, 주소 `pace-rise-node.com`.
