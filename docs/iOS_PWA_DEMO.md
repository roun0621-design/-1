# TER-001 — iOS 실기기 구동

> 평가 항목: **"iOS 실기기 구동 화면(스크린/시연) 보유 여부"**

## 1. 결론 (정직한 현황)

- 본 서비스는 **PWA(Progressive Web App)** 로, **iOS 실기기(아이폰/아이패드)에서 즉시 구동**됩니다.
  - Safari 접속 + **홈 화면에 추가**(Add to Home Screen) → 주소창 없는 **풀스크린 앱**으로 동작.
  - iOS **16.4 이상**: 설치형 PWA에서 **웹푸시 알림**까지 동작.
- **Android**: 네이티브 앱 패키지(TWA, `com.pacerise.node`) 빌드 완료 — Google Play 등록 진행.
- **iOS 네이티브 앱(App Store 바이너리)**: 미빌드 (Apple D-U-N-S 등록 단계). 단, **실기기 구동 자체는 PWA로 충족**.

> 즉 "iOS 실기기에서 구동되는 화면"은 **지금 바로 시연·캡처 가능**합니다.
> 평가가 "App Store 네이티브 앱 심사통과본"을 요구하는 경우에만 별도 작업(아래 §4)이 필요합니다.

---

## 2. iOS 실기기 구동·캡처 단계 (5분)

1. 아이폰 **Safari**에서 접속: `https://pace-rise-node.com`
2. 하단 **공유 버튼(⬆️)** → **"홈 화면에 추가"** → 추가
3. 홈 화면에 생긴 **PACE RISE 아이콘** 실행 → **풀스크린 앱**으로 열림 (주소창 없음)
4. 아래 화면들을 **스크린샷(전원+볼륨업)** 또는 **화면 녹화**로 캡처
5. (선택) 알림 허용 팝업 → 허용하면 웹푸시 동작 확인

> 기기 정보(예: iPhone 15 / iOS 17.x)가 보이도록 **설정 > 정보** 화면도 1장 같이 캡처하면 "실기기" 증빙에 좋습니다.

---

## 3. 캡처할 화면 체크리스트

- [ ] 홈 화면의 **PACE RISE 앱 아이콘** (설치된 모습)
- [ ] **대시보드**(종목 매트릭스) — 풀스크린 구동
- [ ] **실시간 결과/LIVE** 화면
- [ ] **전광판/오버레이**(`/monitor.html`) — 관중 화면
- [ ] **기록입력**(`/record.html`) — 운영 화면
- [ ] (행사용) **간편 기록입력** `/e/<브랜드>/record`
- [ ] **푸시 알림** 수신 화면 (iOS 16.4+)
- [ ] **설정 > 정보**(기기 모델/iOS 버전) — 실기기 증빙

---

## 4. (필요 시) iOS App Store 네이티브 앱 경로

평가가 네이티브 앱 바이너리를 요구할 경우:

| 방식 | 설명 | 비고 |
|---|---|---|
| **Capacitor 래핑** (권장) | 현재 PWA 자산을 그대로 WKWebView로 감싸 App Store 제출 | 화면/로직 재사용, 서버 수정 시 즉시 반영 |
| PWABuilder iOS | PWABuilder의 iOS 패키지 생성 | Android(TWA)와 동일 워크플로 |

- 선행 조건: Apple Developer 계정(법인) + **D-U-N-S 등록**(진행 중).
- 작업량: 셸 프로젝트 생성 + 아이콘/스플래시 + 권한(알림) 설정 + 심사 제출.

---

## 5. 평가 답변(요약 문구)

> 본 서비스는 PWA로 iOS 실기기(아이폰/아이패드)에서 홈 화면 설치 후 풀스크린 앱으로
> 구동되며, iOS 16.4+에서 웹푸시 알림까지 동작한다(실기기 구동 화면 별첨). Android는
> 네이티브 패키지(TWA)를 빌드해 Google Play 등록을 진행 중이며, iOS App Store 네이티브
> 앱은 Apple 법인 인증(D-U-N-S) 완료 후 Capacitor 래핑으로 제출 예정이다.
