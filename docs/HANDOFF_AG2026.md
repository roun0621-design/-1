# 인계 노트 — 2026 아이치·나고야 아시안게임 육상 (9/23 수 ~ 9/29 화)

이 파일은 **다른 맥(맥북)에서 Claude Code 를 열었을 때 대회 상황을 바로 이어받기 위한 것**. Claude 의 개인 메모리는 맥마다 따로라서, 대회 기간 필요한 사실은 전부 여기에 둔다. 새 세션은 이 파일부터 읽고 시작한다. (마지막 갱신 2026-09-26)

## 사용자 · 작업 방식
- 사용자는 PACE RISE 운영자. 요청은 짧고 구어체, 폰(아이폰) 화면 기준으로 판단. 위치·공간·아이콘 일관성에 예민. 이모지 대신 선 아이콘(`public/lib/icons.js`).
- 모든 변경은 `genspark_ai_developer` 브랜치에 커밋·푸시 → 사용자가 배포(`./scripts/deploy.sh`). 커밋 전 `BROWSER_TESTS=1 npx vitest run tests/browser` + 관련 테스트.
- 화면 확인은 puppeteer(폰 393×852)로. 이미지 판독이 안 될 때는 검수용 서브에이전트(general-purpose)에게 PNG 를 읽혀 잘림·정렬을 확인시킨다.
- 답변은 한국어, 원인 → 수정 → 확인 순으로 짧게.

## 운영 정보
- 운영 URL `https://pace-rise-node.com` (www 도 200 이지만 **다른 origin** — 대회 끝난 9/30 이후 nginx 에서 www → 무-www 301 예정). 운영 DB PostgreSQL. **아시안게임 대회 id = 63** (`/dashboard.html?comp=63`).
- 공식 결과 API(Bornan): `https://back.results.asiangames2026.org/s/AG2026/en/ATH/…` — `schedule/daily/<날짜>`, `entries/event/<키>`, `results/<유닛키>`. 코드 `lib/intl/bornan.js`(파싱) `lib/intl/sync.js`(동기화) `lib/intl/placing.js`(순위·진출) `lib/routes/intl.js`(관리자·명단·spotlight API). 문서 `docs/INTL_SYNC.md`.
- 동기화 주기: 결과 60초(시작 −1h~+12h), 스타트 리스트 10분(−36h~−1h), 엔트리 1시간. 경기 전(START_LIST) 응답의 기록은 무시, 사라진 기록은 삭제, RUNNING 이면 기록 없어도 진행 중.
- 한국기록(NR)은 우리 `event_record`(national) 59개와 비교해 우리가 판정(주최 측은 안 줌). 공식 결과면 기록표 갱신 + `record_breaking_log` 자동 승인 + 같은 종목 모든 라운드 PB/SB 전파.
- 한국 선수 42명, 한글 이름·PB·SB 는 사용자 xlsx 로 넣었음(동기화가 덮지 않음).

## 앱 기능 상태 (대회용, 전부 배포됨)
- 대시보드: 기본 시간별 정렬, 열면 '지금' 종목으로 스크롤(중앙) + NEXT 칩/LIVE 배지 깜빡임(JS), 카드 태극기 옆 상태 칩(준결승/결승 진출·탈락·최종 순위 메달), '한국 선수' 필터, 폰 필터 패널, 머리글 새로고침·메뉴 버튼.
- 결과·LIVE 창: 위 '한국 선수' 블록(이름·순위·기록·NR/PB 태그·진출), 아래 진출 규칙·진출자, 기존 기록 칩(WR·AR·GR·NR, 탭하면 보유자·종전), 필드 시기표(높이 O/X·거리 시도별), **이미지 저장**(인스타용 1080×1350 결과 이미지, 조마다 한 장; 사파리·홈화면앱=공유창, 앱스토어 앱=전체 화면→스크린샷).
- 스타트 리스트: PB/SB, `5/7` 순번(PB 기준), 한국 선수 블록 `RANK 5/7 · 전체 23/25`.
- 대표팀 명단: 선수별|종목별, 메달 집계, 네이버 검색 `아시안게임 육상 이름`. 국제대회에선 결과 줄 기록 카드(›) 없음.
- 닫기 X 는 전부 `prCloseBtn()` 공통, 아이콘 선 굵기 통일. 창 스크롤 잠금은 횟수 세기(`lockBodyScroll`).
