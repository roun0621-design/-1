1. 설명 문단이 UI 를 지배: 업로드 탭 카드 9개 전부 열 정의 5~8줄 줄글, 시스템 탭의 4색 "운영 가이드", 외부 API 코드 블록, 기록 관리의 매뉴얼 문장.

3. 버튼 난립: 높이 16~53px 10종, 채움 4색 + 아웃라인 + 텍스트 + 링크형 + 브라우저 기본 파일 버튼. 업로드 탭 버튼 109개(16px '해제' 87개).
4. 빈 화면·깨진 화면: 종목 관리 하단 버튼 4개가 한 글자씩 세로(폭 36px), 선수 관리 빈 상태에 "USER" 글자, 제목만 있는 카드 2개.
5. 랜딩(현황)이 비어 있음: KPI 4개 + 링크 5개 + 원문 로그. 오늘 일정·경고·다음 라운드 없음.
6. 타이포 무체계: 10~14px 6종 혼재(선수 관리 10px 요소 765개), 알파벳 원형 배지(R/S/U/L/J/E)가 아이콘 대용, 이모지·유니코드 기호(⚠ ⭐ ♂♀ ※ ①②).
7. 기술·내부 용어 노출: "(JWT)", "/login.html", "athlete.phone 컬럼", "ANTHROPIC_API_KEY", "OpenClaw on Mac mini", User-Agent 원문.

## 4. 목표 정보구조 — 6묶음 14화면
사이드바는 **화면만** 나열한다(카드 앵커 없음). 화면 안의 구획은 상단 가로 서브탭.

```
현황            오늘 진행 상태 · 경고(체크리스트의 빨강/주황만) · 최근 활동
대회            대회 설정 [기본 정보 | 표시·브랜딩 | 문서 서명·로고 | 위험 구역(복제·초기화·삭제)]
                국제대회 동기화 (sync_source 있는 대회만)
                운영 체크리스트
준비            가져오기 [명단 | 조편성 | 종목 | 시간표 | 배번·연락처]   ← 업로드 탭 + 양식 다운로드
                선수  (전폭 테이블 + 검색·필터 + 우측 드로어)
                종목  (전폭 표 + 드로어; 부 관리는 여기 서브탭)
진행            기록 관리 [승인 큐 | 기록표(NR·DR·CR) | 시리즈]
                계측 가져오기 [.lif | 기록 엑셀 | .txt | 기록카드 사진]   ← 스코어보드 탭에서 분리
                합동 종목
                되돌리기 · 운영 로그
결과·문서       문서·다운로드 [다운로드 | 양식 설정(공통 1벌: 로고·이름·표시 컬럼)]  ← 종합·연맹·중고연맹·ID카드 전부, 연맹에 맞는 것만
                상장 [발급 | 양식(PDF·워드 한 목록) | 이력]
                알림 [푸시 공지 | 문자 설정 | 문자 발송 | 이력]
시스템          사용자·키 [계정 | 심판 운영키 | 기본키·기록위원키 | 외부 API 키] 
                페이싱 라이트
                브랜드·홈 [로고·심판장 | 홈 콘텐츠 | 팝업]
                마스터 [연맹 | 부]
                백업·복원
                (도움말: 기록 시스템 가이드·API 사용법은 화면 우측 ⓘ 패널로, 메뉴에서 제거)
```
- 규칙 1: **대회를 고르면 그 대회에 해당하는 화면만** 보인다(국제 동기화·중고연맹 기록지·행사 브랜딩).
- 규칙 2: 역할 필터는 **사이드바에서** 건다(운영자: 준비·진행·결과·문서 / 매니저: +사용자·키 / 관리자: 전부).
- 규칙 3: 위험 작업은 화면 맨 아래 단일 "위험 구역" 패턴 + 확인 모달. 사이드바에 절대 안 나옴.
- 규칙 4: "새 대회 만들기"는 대회 선택창 옆 버튼으로.
- 중복 정리: 심판장·기록주임·로고는 대회 설정 ▸ 문서 서명·로고 **1벌**로 통합하고 문서·상장이 그 값을 읽는다. 발송 대상 선택(종목·라운드·순위 범위)은 상장·문자가 **같은 컴포넌트**를 쓴다. 백업은 시스템 ▸ 백업·복원 한 곳.

## 5. 비주얼 시스템 (운영 제품 기준)
- 레이아웃: 사이드바 224px(스크롤 없이 다 보이게, 6묶음 14항목), 콘텐츠 최대폭 1200px, 12컬럼/24px. 화면당 스크롤 2장 이내.
- 타이포 6단계만: 12 캡션 / 13 보조 / 14 본문 / 16 카드 제목 / 20 화면 제목 / 28 KPI(tabular-nums). 10·11px 금지. 영문 부제·기술 용어는 제목에서 제거(툴팁으로).
- 카드 한 종류: 흰 배경 · 1px 보더 · 8px 라운드 · 24px 패딩. 좌측 컬러 보더·배경색 설명 박스 폐지. 설명은 1줄까지, 그 이상은 "형식 안내" 접이식 또는 ⓘ. **카드 속 카드 금지**(서브 구획은 구분선 + 13px 레이블).
- 버튼 4종만: Primary(골드, 화면당 1개) / Secondary(아웃라인) / Tertiary(텍스트+아이콘) / Destructive(빨강+확인 모달). 높이 32px 단일(표 안 28px 아이콘). 파일 입력은 드롭존 컴포넌트 하나로. 파일 형식은 색이 아니라 아이콘+라벨.
- 표: 헤더 13px 회색, 행 40px, 하단 1px 구분선, 숫자 우측 정렬 tabular-nums, 상태는 배지 컬럼, 행 액션은 hover 아이콘(상시 '해제' 87개 금지). 큰 목록(선수 817·시간표 87·종목 72)은 전폭 표 + 검색/필터 + 우측 드로어.
- 빈 상태 컴포넌트 하나: 24px 라인 아이콘 + 제목 1줄 + 설명 1줄 + CTA 1개. 내용 없는 카드는 렌더하지 않음.
- 색: 골드는 Primary·활성에만, 의미색 4(성공·주의·오류·정보), 회색 6단계. 아이콘은 Lucide 20px 단일 세트, 항목별 고유 아이콘, 이모지·알파벳 배지 폐지.
- 현황 화면: 오늘 진행(진행 중·다음 라운드·미완료) → 경고 목록 → 최근 활동(카테고리 배지·시각·주체 컬럼) 3구역.
