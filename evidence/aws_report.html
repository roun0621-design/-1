3 AWS 콘솔 캡처 가이드 (직접 캡처용)
AWS 콘솔 화면은 계정 보유자(본인)만 접근 가능하므로 직접 캡처가 필요합니다. 아래 화면들을 캡처하면 충실한 증빙이 됩니다:
  1. EC2 인스턴스 목록 — EC2 → 인스턴스 → 실행 중 인스턴스(이름·타입·퍼블릭 IP·서울 리전이 보이도록)
  2. RDS 데이터베이스 (RDS 사용 시) — RDS → 데이터베이스 → PostgreSQL 엔진·상태(Available) 화면
  3. 보안 그룹 / 인바운드 규칙 — 443(HTTPS), 80, 5432(DB) 포트 규칙
  4. 리전 표시 — 콘솔 우측 상단 "서울 (ap-northeast-2)" 가 보이도록
  5. (선택) VPC / 로드밸런서 / Route 53 사용 시 해당 화면
Tip: 각 화면 우측 상단의 리전(서울) 과 계정/리소스 식별자가 함께 보이도록 캡처하세요. 민감정보(계정 ID 전체, 비밀키)는 가려도 무방합니다.
